# SOC-Analyst-Writeups
My SOC Analyst path: labs, tools, notes, detections and incident investigations.

I focus on building practical skills in:
- Security event analysis  
- Log investigation  
- Attack detection  
- Understanding attacker behavior  

---

##  Repository Structure

###  tools/
Writeups on security tools and frameworks (e.g. Metasploit, Hydra, Burp Suite), including how they are used by attackers and how their activity can be detected.

###  notes/
Core cybersecurity concepts such as networking, HTTP/HTTPS, and system fundamentals, explained with a focus on real-world security usage.

###  soc-cases/ *(in progress)*
Simulated SOC scenarios involving alert analysis, incident investigation, and response.

###  screenshots/
Supporting images used in writeups.
